PART 2

🧩 三大架构创新详解

V4 在 V3 的 MoE + MTP 基础上引入了三项核心创新，彻底改变超长序列处理的效率格局。

🔬 混合注意力：CSA + HCA

CSA（压缩稀疏注意力）：将每 m=4 个 Token 的 KV 压缩为 1 条，再用 Lightning Indexer 选 top-k=512 条做稀疏注意力。
HCA（重度压缩注意力）：更激进地将 m'=128 个 Token 压缩为 1 条，但保持全注意力。
两者交替使用，外加 128 窗口滑动注意力保留局部细粒度信息。

🌐 流形约束超连接 (mHC)

将残差映射矩阵约束到双随机矩阵流形（Birkhoff 多面体），保证谱范数 ≤ 1，使深层网络中信号传播非扩张且稳定。通过 Sinkhorn-Knopp 算法（20 次迭代）投影，配合动态参数化生成三个映射矩阵。

⚡ Muon 优化器

替代 AdamW 用于大部分参数训练（embedding、预测头和 RMSNorm 仍用 AdamW）。momentum=0.95，weight_decay=0.1。实现更快收敛和更好的训练稳定性。

✅ DeepSeek V4 的优势

• 上下文长度领先：1M vs 256K，4 倍差距
• 推理效率革命：混合注意力使长上下文推理成本极低
• 代码竞赛顶尖：Codeforces 3206、LiveCodeBench 93.5%
• Agent 全面领先：SWE-Verified 80.6%、BrowseComp 83.4%
• 知识能力强：SimpleQA 57.9%，开源遥遥领先
• MIT 开源：最宽松许可，商用友好

✅ Hy3 Preview 的优势

• 超高效率比：仅 21B 激活即达相当竞争力，部署成本低
• Base 模型数学强：MATH 76.3% 远超 V4-Pro Base 的 64.5%
• 进步飞速：BrowseComp 28.7%→67.1%，SWE 53.0%→74.4%
• 中文学术场景：清华数学博资考 88.4 avg@3，生物竞赛 87.8
• 腾讯生态：ModelScope / GitCode / cnb.cool 多平台

🔍 五大核心发现

1. V4-Pro 确立开源编码之王 — LiveCodeBench 93.5%、Codeforces 3206 均为全场最高，开源模型首次在编码竞赛中超越所有闭源模型。在 Codeforces 人类排行中位列第 23 名。

2. Gemini 3.1 知识称王 — SimpleQA 75.6%、MMLU-Pro 91.0% 明显领先。V4-Pro 以 57.9% 大幅超越其他开源模型（K2.6 仅 36.9%），但距 Gemini 仍有差距。

3. 数学推理 GPT-5.4 最强 — HMMT 97.7%、IMO Answer 91.4% 均为最高。V4-Pro 紧随其后（95.2%、89.8%），差距很小。

4. 长上下文 V4 优势明显 — 1M token 下 CorpusQA 62.0% 大幅领先 Gemini 的 53.8%。

5. Hy3 以小博大 — 仅 21B 激活参数却进入开源第一梯队。从 Hy2 到 Hy3 的巨大飞跃（SWE 53.0%→74.4%）令人瞩目。

PART 5

📝 总结与展望

2026 年 4 月，大模型竞争进入新阶段。DeepSeek V4 和 Hy3 Preview 几乎同日发布，代表了开源大模型的两种不同进化路径：

DeepSeek V4 — "效率为王"：通过 CSA+HCA 混合注意力架构彻底解决百万 Token 上下文的推理成本问题，同时以 1.6T 参数量确保旗舰级绝对性能。首次让开源模型在编码竞赛中超越闭源模型。MIT 许可为社区和商业应用扫清障碍。

Hy3 Preview — "小而强"：以 295B/21B 的紧凑参数量实现了令人印象深刻的性能。从 Hy2 到 Hy3 的巨大飞跃预示着混元系列的快速追赶态势。

开源与闭源的差距正在快速缩小。
开源大模型的"超级时刻"正在到来。
