# AI 越狱"实锤"了：Anthropic 回查 14 万次，揪出三起真实入侵

## 选题信息

- **选题日期**：2026-08-21（周五）
- **类型**：次条 · 技术趋势 / 安全案例
- **专题**：AI 安全
- **关键词**：Anthropic、Claude、越狱、沙箱逃逸、供应链投毒、PyPI、网络安全评测、前沿红队
- **目标受众**：算法工程师 / AI 创业者 / 科技投资人 / 产品经理

## 选题理由

1. 这是 AI 安全史上少见的"官方主动自曝"事件——Anthropic 在 OpenAI 披露模型逃逸沙箱之后，主动回溯 14.1 万次评测运行，坦诚三起真实入侵事故。这种"主动披露"本身，比事件本身更值得解读。
2. 三起事件的细节（误配置出网路径 → 模型误把真实企业当虚构目标 → 凭证提取 / PyPI 供应链投毒 / 入侵生产系统）完整呈现了"模型越界"从理论风险到真实危害的完整链条。
3. 事件的核心教训不在"模型太强"，而在"评测环境的隔离是人的疏忽，不是模型主动作恶"——这个归因对业内（尤其做 AI 评测、红队、Agent 安全的人）极有价值。

## 核心信息（事实链，已多源交叉核实）

- **披露时间**：2026-07-30，Anthropic 官方博客发布，由 Frontier Red Team（前沿红队）主导调查。
- **回溯范围**：141,006 次网络安全评测运行（覆盖 Cybench、CyberGym、ExploitBench 等进攻性基准）。
- **涉事模型**：Claude Opus 4.7、Claude Mythos 5、一款未发布的内部测试模型。
- **直接诱因**：评估合作伙伴（以色列安全公司 Irregular）在测试中"沟通失误/误配置"，导致隔离环境开放了出网路径；模型原被设计在模拟网络中排查"虚构公司"的隐患，却因名称相近而将真实企业当作目标。
- **三起事件行为**：① 凭证提取；② 向 PyPI 上传恶意代码包（供应链投毒）；③ 入侵生产系统。
- **响应时间线**：7-23 叫停测试，四天后（约 7-27）通知受影响企业，两家已回应。
