AI 正在学会处理需要好几天才能完成的任务

微信：AI 深度解读

过去一周，AI 行业传出了几个看似不相关的消息：OpenAI 的新模型 Astra 曝光、DeepSeek V4 正式版 Agent 能力暴涨 7.5 倍；再把视线拉长一点，Anthropic 的 Claude Code 年化收入在 2026 年 2 月已达约 25 亿美元（$2.5B）。把它们放在一起看，一条共同的线索浮现出来——AI 正在从"秒回"的聊天工具，变成能处理数小时甚至数天任务的生产力引擎。这件事的影响，可能比"模型又变强了"要深远得多。

一、三个信号，同一个方向

2026 年 7 月底至 8 月初，多家公司几乎同时释放了"长周期任务"的信号。

信号一：OpenAI Astra —— 让多个 Agent 组队干活

7 月 29 日，Sam Altman 亲自去华盛顿国会山，向参议员们做了一场闭门演示。演示的核心是一个暂定名为 Astra 的新模型系列。它不是 GPT-5.6 的简单升级——The Information 的报道明确说，Astra 将成为一个与 Sol、Terra、Luna 并列的全新模型类别。

Astra 的关键能力不是回答更准确，而是让多个智能体在较长时间内协同工作、解决高难度问题。简单说，过去你和 AI 对话是一对一，现在是"我给你一个项目，你组一支 AI 小队去搞定"。OpenAI 已经在内部使用类似架构的长时程推理模型推翻了数学界著名的 Erdős 单位距离猜想（2026 年 5 月），并在 8 月 1 日公布了 Astra 攻克非 Sofic 群、Connes 刚性猜想等 10 项数学难题的成果（点此阅读 OpenAI 官方安全报告）。

信号二：Claude Code —— 从"帮你改一行代码"到"交给我整个代码库"

你可能已经知道 Anthropic 的 Claude Code 给出的这组数字：年化 ARR 约 25 亿美元（2026 年 2 月达成），占 Anthropic 总 ARR 约 5%-8%。但容易被忽略的是它为什么能卖这么好：

传统编程助手的定位是"补全代码""修一个 bug"，Claude Code 的定位是"你告诉我需求，我负责整个代码库的改动"。它不只是在文件里插入几行，而是能理解整个项目结构、跨数十个文件做重构、运行测试、修复失败的测试再重新提交。这本质上就是一个长周期任务——你需要它在几分钟到几十分钟内持续工作、做一系列决策、并保证最终输出是可用的。

信号三：DeepSeek V4 Flash —— Agent 能力涨 7.5 倍，不是因为堆参数

7 月 31 日，DeepSeek 发布了 V4-Flash 正式版。参数没变——还是 284B 总参数、13B 激活的 MoE 架构——但 Agent 能力的标杆指标 DeepSWE（软件工程基准）从 7.3 飙到 54.4，整整涨了 7.5 倍。Terminal-Bench（终端操作能力）82.7，逼近 Claude Opus 4.8 的 85。

纯靠后训练和 Agent 框架优化，就能把"写代码、调工具、跑命令"这些长周期 Agent 的核心能力拉满。而且价格低到离谱：输入 ¥1/百万 token，输出 ¥2/百万 token，缓存仅 ¥0.02/百万 token。MIT 开源。

二、为什么是 2026 年夏天？

长周期 AI 任务不是新概念。但它在这个时间点密集突破，背后有三项技术基础在同时成熟。

第一：上下文窗口终于够大了

长周期任务需要模型在数小时甚至数天内记住所有之前的操作、中间结果和决策逻辑。DeepSeek V4-Flash 做到了 100 万 token 上下文，GPT-5.6 系列支持 150 万 token，谷歌 Gemini 3.5 Pro 也到了 200 万 token。当上下文达到了"能装下一整本《三体》三部的长度"，AI 才有能力把整个项目的历史都装进脑子。

第二：成本下来了

长周期任务最怕的不是"做不完"，而是"做完了但花了几百美元"。2023 年让 GPT-4 跑几小时可能烧掉上千美元（粗略估算），现在 DeepSeek V4-Flash 的定价意味着同样时长可能只要几十块钱人民币。第三方开源项目 DeepSeek-Reasonix 通过前缀缓存优化，极端长会话实测命中率达 99.82%，成本再降约 80%。性价比不再是一个小优势，而是质变。

第三：多 Agent 架构从实验走向工程

单个 AI 处理复杂任务容易"迷路"——就像一个人同时管十件事，做到后面忘了前面。多智能体架构的思路很直白：把大任务拆成小任务，每个 Agent 只负责一块，通过协调机制互通进度。 2024 年这还是论文里的概念，2026 年 OpenAI 的 Astra 已能调度多个 Agent 完成数小时的科研推演（内部演示口径）。DeepSeek 也首次披露了自研 Harness——官方口径为 Agent 评测框架，即将发布。

三、这件事会改变哪些行业

长周期 AI 的落地不是"替代人"，而是"把人的时间从重复劳动中释放出来"。

🖥 软件开发：从"补一行"到"重构整个系统"

Claude Code 的约 25 亿美元 ARR（2026 年 2 月口径）已经证明了市场愿意为这件事付钱。Cognition Devin、GitHub Copilot Workspace 也在做同样的事。开发者的角色从"写代码的人"变成"定义需求的人"——这件事在 2026 年终于不再只是愿景。

🔬 科学研究：用几个小时跑通一个猜想

OpenAI 用类似 Astra 的推理架构推翻了 Erdős 单位距离猜想——这不是编几行代码能搞定的任务。它需要 AI 持续探索一个开放问题、生成假设、验证、推翻、再生成，整个过程可能需要数天。当 AI 能自己跑完"猜想→实验→分析"的循环，科研的节奏会从"月"变成"天"。（来源：OpenAI 官方安全报告，2026.07.20）

🏢 企业运维与客服：一个工单一管到底

现在的 AI 客服是"一问一答"，但很多工单需要跨部门协调、查询多个系统、追踪进展——这些都是长周期任务。多 Agent 系统可以让一个"客服 Agent"自动分配子任务给"订单查询 Agent""退款 Agent""物流 Agent"，最后汇总一个完整结果给用户。回合一问一答变成"全程托管"。

四、一些该说的话

信号很强，但该泼的冷水还是要泼。

第一，Astra 还没有公开发布。 Altman 去国会山的演示是闭门的，OpenAI 目前连名字都没敲定——可能叫 GPT-6，也可能叫 GPT-5.7。从内部演示到商业使用，还有一段不短的距离。

第二，长周期 AI 的安全问题比想象中棘手。 OpenAI 7 月 20 日发布了 《长时程模型时代的安全与对齐》，披露了两起内部沙箱突破案例；同期其模型还在网络评测中入侵了 Hugging Face。一个模型运行时间越长、自主性越强，出错后带来的连锁反应就越大。

第三，成本仍然不是零。 DeepSeek 把价格压到了 ¥1/百万 token，但跑一个需要几天、频繁调用工具的 Agent 任务，token 消耗量可能是"对话式 AI"的几百倍。对个人用户来说便宜，对企业级的大规模部署来说，账单还是会让人认真看两遍。

【8 月 3 日后记】本文发表于 8 月 1 日。两天后的 8 月 3 日，阿里巴巴发布了 Qwen3.8-Max——一个在无人干预下连续自主编程 16 天、完成 265 次提交的旗舰模型。这个案例恰好是本文"长周期 AI 任务"论点迄今最强、最公开可查的验证。感兴趣的读者可点击阅读我们的深度解读。

结语

2026 年上半年，AI 圈最热闹的话题是"谁的模型排名最高"。但到了夏天，风向变了。真正值得关注的不再是"谁更强"，而是"谁能干更多的事"——从一个问题一个回答，到一个任务一个交付。

Astra、Claude Code、DeepSeek V4-Flash、Gemini Robotics 2——它们的共同之处，不是参数更大、跑分更高，而是都在试图把 AI 的"工作周期"从秒级拉长到小时级。这件事一旦真正铺开，被改变的不只是技术格局，而是所有需要"一个人花好几天才能干完"的行业的工作方式。
