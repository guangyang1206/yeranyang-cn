## 三、选题推荐

### 头条：模型开始造自己了——Hy4 preview 与递归自我改进的第一道裂缝

- **角度说明**：不停留在"770B / 1M 上下文"的参数播报。真正的信号藏在官方披露里最不起眼的那句——Hy4 preview 首次参与训练方法、数据策略、评估体系和底层算子的自动优化，模型自己提方案、跑实验、看结果继续迭代，端到端推理吞吐提升 31.8%。这意味着模型开始参与"造自己的工具"，而不只是被调用。文章要把这条路径讲清楚：它和 Scaling 是什么关系，和 Rich Sutton 同一天提出的"持续学习"破局思路有什么不同，以及"递归自我改进"这个词被滥用到什么程度、真实边界在哪里。
- **受众匹配度**：★★★★★（算法工程师关心自我改进的实现路径与可复现性；AI 创业者关心这条路径会不会改变竞争格局；投资人关心它能否成为 Scaling 之外的新增长曲线；产品经理关心这意味着能力迭代速度会怎么变）
- **差异化亮点**：
  1. 严格区分「模型优化推理基建」（已发生、可量化、31.8% 是硬数字）与「模型自主改进训练配方」（官方表述为"首次参与"，程度需审慎解读），不把两者混为一谈渲染成"AI 已经能自己造自己"
  2. 严格标注 2.99/4 是腾讯内部盲测而非公开榜单，领先 GLM 5.3（2.92）、Kimi K3（2.94）的幅度是 0.05~0.07 分，属于"略优"而非"碾压"
  3. 把 Hy4 与同周 Rich Sutton 的"局部最优"论并置，形成两条破局路径的对照，而不是孤立地夸一个模型
  4. 不制造"AI 自我进化失控"焦虑，重点讲清楚工程闭环的实际形态与当前局限

### 次条1：129 亿美元买下 AI 界的 GitHub——英伟达为什么要买 Hugging Face

- **角度说明**：从"80 倍 ARR 溢价"这个数字切入，讲清楚英伟达买的不是模型、不是代码，是开发者入口与分发心智。核心问题：当闭源巨头都在自研芯片，GPU 正在变成大宗商品，英伟达的护城河还能靠什么守住？顺带对比 Stripe 收购 OpenRouter，说明"AI 中间层"正在成为产业争夺焦点。
- **受众匹配度**：★★★★☆（投资人、创业者、关注开源生态的工程师）
- **差异化亮点**：不渲染"开源社区被资本收编"的情绪叙事，聚焦交易背后的商业逻辑与开源中立性面临的真实张力。

### 次条2：中国 AI 公司的收入真相——ARR 狂欢下的口径游戏

- **角度说明**：本周 MiniMax ARR 涨 5 倍、DeepSeek 冲 740 亿估值，数字都很漂亮。但 ARR 是"按当前水平折算一年的收入"，不是已到账的钱。这篇给读者一套判断框架：ARR 与实际营收差在哪、B 端占比变化说明什么、估值/ARR 倍数处于什么区间算合理。
- **受众匹配度**：★★★★☆（投资人、关注行业真实健康状况的从业者）
- **差异化亮点**：不做"泡沫要破了"的焦虑叙事，而是提供可复用的财报阅读方法论，符合"让普通人也能了解 AI"的定位。
