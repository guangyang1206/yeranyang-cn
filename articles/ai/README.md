## 📋 内容准则（2026-05-18 确立）

> **不为流量写作，为读者负责。** 这是「烨然漫笔」的底线。

### 信息源标准
1. **只引用权威一手信源** — 优先使用：The Information、Reuters、Bloomberg、澎湃新闻、界面新闻、36氪深度报道
2. **必须有明确出处的引用** — 每个数据点标注来源 `[1][2]...`，参考文献列在文末`
3. **不转载二手消息** — 不引用"知情人士透露"类无法核实的内容`
4. **不依赖社交媒体信源** — 不以 X/Twitter、知乎、即刻等自媒体言论作为核心论据`
5. **多源交叉验证** — 重要数据至少两个独立来源确认`

### 内容红线
1. **绝不做标题党** — 标题准确概括内容，不夸大、不耸动、不制造焦虑`
2. **绝不蹭热度** — 不追无价值的流量热点，只写有深度、有判断的内容`
3. **不为流量伤害判断** — 不写"震惊""突发""删前速看"类内容`
4. **不制造 AI 焦虑** — 不渲染"AI 取代人类""失业恐慌"，客观分析影响`
5. **绝不编造数据** — 所有数据必有引用源，虚构数据零容忍`

### 风格定位`
> **为理想主义者鼓与呼，为普通人带来清晰易懂的信息。**
- 语言平实，不炫技`
- 复杂概念用类比讲清楚`
- 尊重事实，尊重读者`
- 不装、不水、不煽情`

## 目录规范`

```
yeranyang-cn/
├── README.md              # 仓库总 README（文章清单 + 使用说明）
├── .gitignore
├── scripts/               # 自动化工具`
│   ├── new-topic.sh       # 选题脚手架生成器`
│   └── update-index.sh    # 索引更新脚本`
└── articles/ai/           # 所有 AI 选题归档在这里`
    ├── README.md          # 本文件（索引 + 规范）
    ├── index.html         # 网页版文章合集（数据驱动）
    ├── articles.json      # 文章元数据
    └── YYYY-MM-DD_slug/        # 每个选题独立目录`
        ├── README.md           # 选题元数据 & 发布追踪`
        ├── article-wechat.html  # 公众号专用版（内联样式，复制粘贴）
        ├── article-full.html       # 个人网站全文版（深色科技风）
        ├── article-illustrations.html # 文章内文配图素材（手绘风格）
        ├── cover-assets.html       # 公众号封面/缩略图素材`
        ├── prompts/                # AI 生图 prompt（如有）
        └── assets/                 # 参考资料、图片素材`
```

## 命名规则`

| 元素 | 规则 | 示例 |
|------|------|------|
| 日期 | `YYYY-MM-DD` 创作日期 | `2026-04-24` |
| slug | 英文 kebab-case，2-5 个词 | `deepseek-v4-deep-dive` |
| 组合 | `日期_slug` 下划线连接 | `2026-04-24_deepseek-v4-deep-dive` |

## 文件职责`

| 文件 | 用途 | 使用方式 |
|------|------|----------|
| `README.md` | 选题元数据 & 发布追踪 | 每次发布后更新状态 |
| `article-wechat.html` | 微信公众号正文 | 浏览器打开 → Ctrl+A → 粘贴到编辑器 |
| `article-full.html` | 个人网站全文版 | 部署到个人网站 |
| `article-illustrations.html` | 文章内文配图素材 | 浏览器打开 → 逐张截图 |
| `cover-assets.html` | 公众号封面/缩略图 | 浏览器打开 → 截图对应尺寸 |
| `prompts/` | AI 生图的 prompt 文本 | 备份用，方便复用和微调 |

## 发文流程`

```bash
# 1. 新选题：生成脚手架`
./scripts/new-topic.sh "标题" [slug]

# 2. 写作完成 → 编辑审核 → 发布`
# 3. 发布后：更新 README.md 状态标志`
# 4. 部署到个人网站：python3 scripts/deploy.py（内网站点）`
