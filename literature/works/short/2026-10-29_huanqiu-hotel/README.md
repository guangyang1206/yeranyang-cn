# 《环球饭店》（暂名）

- 体量：短篇小说
- 状态：构思中
- 建档日期：2026-10-29
- 核心矛盾：理想与现实
- 时间范围：明线为县城里的一夜，暗线跨越20世纪90年代至21世纪20年代
- 主人公代际：20世纪90年代出生的县城孩子，跨世纪成长的一代
- 地理原型：不使用真实地名；中国北方、太行山南麓，山地向平原过渡，四季分明
- 返乡契机：中学语文老师去世，主人公回来参加告别仪式及答谢席

## 核心命题

一个人年轻时以为理想是改变世界；成熟以后才发现，理想也可以是在世界改变自己的过程中，仍然拒绝把别人当作工具。

## 当前判断

老师的葬礼不是方便人物返乡的情节装置，而是作品第一重伦理现场：人们如何用有限、程式化的语言讲述一个已经不能开口的人。随后出现的网络求助，是第二重伦理现场：人们又将如何讲述一个仍然可以说“不”的女孩。

两者共同指向同一个问题：谁有权讲述另一个人的生命，又该为这种讲述承担什么责任？
