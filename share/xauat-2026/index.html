03 — AI 是什么（1/3）

七十年，三波浪潮。

第一波 · 1956–1980s

符号主义

Symbolism · 基于逻辑推理

用规则和知识库编码专家的思维。代表：专家系统、知识图谱。硬编码，脆弱。

第二波 · 1980s–2010s

连接主义

Connectionism · 基于统计学习

模拟神经元连接，从海量数据里学规律。代表：CNN、RNN、AlphaGo。会自己学。

第三波 · 2017–至今

大模型 & Agent

Foundation Models · 能力开始涌现

Transformer → GPT → 推理 → Agent。规模跨过临界点，会推理、会做事。

AI 发展关键节点 · Timeline 符号主义 连接主义 大模型时代

时间轴综合参考：Andrew Ng 斯坦福 CS230 · Fei-Fei Li ImageNet · Yann LeCun Deep Learning History · 华为开发者社区 AI 简史

📈

本轮浪潮的底座是连接主义：机器从人类历史数据中学习并归纳规律。它不是被“编程”出来的，而是被“训练”出来的——这一点，决定了后面的一切。

03 — AI 是什么（2/3）

大模型的本质：神经网络与一场“猜词”游戏。

大模型主要通过从海量数据中学习来构建能力，其本质是一种基于统计的方法，依赖于统计规律，而非逻辑推理。给定上文，预测下一个最可能出现的语言符号（Token）。

结构本质：输入 中 · 华 · 人民 → 神经网络计算权重 → 输出下一个 Token 的概率分布（Softmax）。它把“学到的世界”编码进了亿万个连接的权重里。

“预测下一个语言符号（Token）的质量，其实反映了你对语言背后隐藏的语义和知识的理解程度。这不仅是统计，更是对世界本质的压缩和表达。”

—— Ilya Sutskever（时任 OpenAI 首席科学家）· NVIDIA GTC 2023 · 2023-03-23
🧠

要把下一个词猜得足够准，模型不得不“顺带”理解这个世界。智能，是在压缩世界的过程中涌现出来的副产品。

Q1

预测下一个词的语言生成，本质是什么？

是基于联合概率的最大值，是马尔科夫链的自然推广；也是信息熵最大、能量最小，符合物理学玻尔兹曼分布与吉布斯分布。 人类语言生成的奥秘，就藏在统计物理与信息论的深层耦合之中——当 GPT 通过最小化信息熵来预测词语时，本质是在遵循玻尔兹曼分布的物理规律，如同粒子在热力学系统里寻找最低熵态。

Q2

神经网络为何能通过学习，记住世界百科知识？

通过人工神经网络架构（ANN），靠激活函数与权重在训练中不断更新获得。 其本质是学习并形成一种高效的信息与知识编码——把亿万数据压进有限的参数里，把“世界”塞进权重里。

03 — AI 是什么 · Extra

Agent 的感知-行动闭环。

一句话总结

Agent 不是让 AI “更聪明”，而是让 AI 从“回答问题”走向“完成任务”——用自然语言说出目标，它自己感知上下文、拆解步骤、调用工具、交付可评审的结果。

The Perception–Action Cycle  ·  感知-行动闭环

五个阶段环环相扣，每一环的输出是下一环的输入——是闭环，不是流水线。

感知 Perception

从文件、工具、用户输入等多源信息里，把当前情境拼起来。

→

推理 Reasoning

理解情境，判断什么最重要、什么是当前的关键约束。

→

规划 Planning

把目标拆解为步骤，选择当前最优的执行路径。

→

行动 Action

调用工具与系统去做——不只是说。

→

反思 Reflection

检查结果、汲取反馈，让下一轮更好。输出回到感知。

Reflection → Perception  ·  反思即新的感知
💡

The key insight: The difference isn’t intelligence — the intelligence was always there. The difference is continuity, context, and connection.

核心洞察：差别不在智能本身——智能一直都在。真正的差别在于连续性（Continuity）、上下文（Context）、连接（Connection）。

04 — 产业在发生什么（4/5）

从大模型到 Agent：从 Demo 到生产的四道门槛。

会写一个惊艳的 Demo 不难，难的是让 Agent 真正“上岗干活”。 MIT NANDA 研究显示：约 95% 的生成式 AI 项目在企业里没能进入生产（Menlo Ventures 2025 State of GenAI 引用）—— 要成为企业里可靠的“数字员工”，Agent 必须回答四个问题。

01

供得起 Affordable

Token 经济学 · 算力 × 电力

调用成本能不能降到规模可用？大模型 API 每年在降价，但 Agent 一次任务动辄消耗 数十万 Token——问题不是“单价”，而是“单位任务成本”。

案例 DeepSeek V4 API 永久降至原价 1/4；Claude Sonnet 4 缓存命中价降至 $0.30/百万 token
02

跑得稳 Reliable

一致性 · 确定性 · 可追溯

企业要的是可复现的执行，不是每次都不一样的“惊喜”。同一个任务，跑十次要有十次都能交付的把握。

现状 Menlo 报告：只有 16% 企业部署是“真 Agent”，其余 84% 仍是固定流程 workflow
03

管得住 Governable

权限 · 审计 · 边界

能授权、能约束、能问责——才敢把真实业务交给它。Agent 每一步 tool call 都要能审计、能撤销、能挂人工审核。

案例 Claude Code 的 permission system；OpenAI Enterprise 的 SOC 2 / HIPAA / 数据不训练承诺
04

会成长 Improvable

从反馈里学 · 越用越好

Agent 不是一次交付的软件，而是持续训练的员工。要能从用户反馈、错误案例、真实数据里迭代——人机协同才是完整图景。

数据 Menlo：AI 交易转化率 47%，是 SaaS（25%）的 1.9 倍——价值一旦被验证，扩散极快

06 — 人往何处

一个工科背景的人，如何在 AI 时代重新定位自己？我的想法是：不必和机器比谁算得快、记得多、做得多，而是主动退到只属于人的那一侧——设计、立法与终极审核：定义什么问题值得解、划定什么是对的边界、对结果负最终的责任。

工科生的核心竞争力，正在迁移。

从 “会写代码” → 到 “会定义系统、会与 AI 协作”
📚

保持学习曲线，把 AI 当成“随身的同事”，而非威胁。

✨

守住人的独特性：好奇 · 判断 · 审美 · 责任——机器越来越擅长前三样的表现，但最终的价值判断与责任承担，只属于人。

🌱
动“手” → 动“脑” → 动“心” 母校教给我的工程思维——拆解复杂系统、对结果负责——恰恰是 AI 时代最稀缺的能力。工具会变，但“把事情做对、并且做对的事情”的人，永远被需要。

“庐山烟雨浙江潮，未至千般恨不消。到得还来别无事，庐山烟雨浙江潮。”——苏轼《观潮》。看过潮起潮落，回到本心，才知道什么真正属于自己。

愿我们既能用好 AI 这把“神笔”，也守得住自己的那颗心。
